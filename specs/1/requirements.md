## 語彙

| 語彙 | 意味 |
|---|---|
| `Terminal` | 拡張が管理対象として識別した窓自身。端末アプリに属する全窓ではない |
| `SameApp` / `Dialog` / `Clipboard` / `Other` | 管理対象ではない同一アプリ窓、ダイアログ、クリップボード補助窓、別アプリ窓 |
| `Monitor` | GNOME が公開する現在の論理モニター。物理出力とは区別する |
| `Panel` | GNOME 標準の上部パネル。同じモニターに存在しない場合、操作対象はない |
| `Reservation` | 作業領域から除かれる予約領域。所有者が `Panel` でない領域は操作しない |
| `mode` | 新しい共通設定。モデルの名前であり、GSettings キー名や UI 文言を指定しない |
| `Desktop` / `Overview` / `Locked` | 通常のデスクトップ、概要、ロック画面 |
| `Saved` / `Maximized` / `Manual` | 保存したサイズ・水平配置による形状、通常の縦横最大化、利用者が変更した形状 |
| `eligible` | 拡張と mode が有効で、Desktop において Terminal が生存・表示中・現在のワークスペースに可視・自身がフォーカス中・非フルスクリーン・縦横最大化であること |
| `showOrRecall` | 既存ショートカットの分岐が表示または呼び戻しを行う操作。従来どおり隠す分岐とは区別する |
| `reconcile` | 現在の条件を再判定し、自分のパネル変更を適用または取り消す抽象操作。具体的 API・通知順序は指定しない |
