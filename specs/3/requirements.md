## 語彙と適用条件

| 語彙 | 意味 |
|---|---|
| `Terminal` | 拡張が管理対象とした窓自身 |
| `Panel` | GNOME 標準の上部パネル。別拡張のパネルは含まない |
| `Monitor` | 現在の論理モニター |
| `Reservation` | 作業領域から除かれる予約領域。所有者ごとに区別する |
| `Launch` | ショートカットによる新規起動と最大化表示 |
| `Recall` | ショートカットによる隠れた最大化 Terminal の再表示 |
| `FocusReturn` | 表示中の最大化 Terminal 自身にフォーカスが確定して戻ること |
| `Click` / `AltTab` / `Shortcut` / `Other` | FocusReturn の方法。Other は列挙外の方法も制限しないための抽象値 |
| `Selecting` | Alt+Tab でフォーカス先を選んでおり、Terminal への復帰は未確定の状態 |
| `Hide` | 既存ショートカットの非表示分岐 |
| `Pending` | Launch の対象窓または表示先 Monitor が未確定の状態 |
| `shown` / `mapped` | Terminal の窓が論理的に表示中であることと、アクターが mapped であること。画面上のピクセルが既に見えたこととは区別する |
| `eligible` | 拡張とパネル自動非表示が有効で、Terminal が生存・shown かつ mapped・現在のワークスペースに存在・自身が実際にフォーカス中・通常のデスクトップ上・縦横最大化・非フルスクリーンであり、同じ Monitor の Panel が操作対象として存在すること |
| 最初の描画 | Launch/Recall は Terminal が見える最初のフレーム。FocusReturn はフォーカス確定後の最初の描画 |
| 自分の変更 | 拡張が実際に変更した Panel の可視性と Panel 自身の Reservation。両者を独立に復元する |
| 上端 | 対象 Monitor の画面上端。上端に他の Reservation がある場合は画面上端への到達を要求しない |

Launch/Recall の表示要求や対象窓・Monitor の確定だけでは、実際の shown・mapped・フォーカスの成立とみなさない。
Panel の非表示と Reservation の解放には、その時点の実状態が eligible を満たす必要がある。
shown と mapped とフォーカスは画面に Terminal が見える最初の描画より前に成立し得るため、その成立後かつ最初の描画までに Panel と配置を反映する。
表示条件だけ、フォーカスだけ、または shown でも unmapped の場合には新たに Panel と Reservation を変更しない。
未確定の窓や Monitor を推測して Panel を先に隠すことは認めない。
要求の期限はミリ秒ではなく画面に見える順序で判定する。
